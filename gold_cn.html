📉 策略回测与收益表现

回测区间为 SGE 上市后（2016-04-18 起）。所有策略均使用前一日估值分位决定当日仓位，避免未来信息。已扣除单边 0.1% 交易成本、4.5% 年化融资成本（仅对仓位 > 1 部分）、调仓阈值 5%。

📐 分段仓位函数 H(q)

输入为估值分位 q，输出为建议仓位（未经上限截断）
q < 0.1（极度低估）：仓位 = 3.0 - 5.0 × q　→ 2.5 ~ 3.0
0.1 ≤ q < 0.3（低估）：仓位 = 2.5 - 5.0 × (q - 0.1)　→ 1.5 ~ 2.5
0.3 ≤ q < 0.7（合理）：仓位 = 1.5 - 2.5 × (q - 0.3)　→ 0.5 ~ 1.5
0.7 ≤ q < 0.9（高估）：仓位 = 0.5 - 2.0 × (q - 0.7)　→ 0.1 ~ 0.5
q ≥ 0.9（极度高估）：仓位 = 0.1　→ 减至最低仓位

设计理念：在低估区间适度加杠杆（最高 3 倍），在高估区间大幅减仓（最低 0.1 倍）。分段点 0.1 / 0.3 / 0.7 / 0.9 对应模型的五个估值区间（极度低估 / 低估 / 合理 / 高估 / 极度高估）。函数在"低估加仓、高估减仓"的方向上单调，但两端不对称——低估时仓位提升空间大于高估时仓位下降空间。不同策略的差别在于仓位上限截断（1.0 / 2.0 / 2.5 / 3.0）。

策略规则与目标

策略分位窗口仓位上限调仓规则与目标
买入持有—1.0始终满仓黄金。目标：展示黄金本身的长期回报，作为所有策略的基准锚点。
极端择时(极度反转)全部历史分位0 / 1 切换极度低估（分位<10%）满仓，极度高估（分位>90%）空仓，其余保持。用状态机避免频繁切换。目标：检验"只在极端信号出现时大幅调仓"是否有效。
表现说明：2016-2026 年间极度低估信号仅出现 15 次（平均持续 3.7 个交易日），导致该策略长期踏空，收益显著低于买入持有。这是纯极端阈值择时的典型局限。
10Y_线性1.0_纯估值10年滚动分位1.0仓位 = 1 - 10年分位，上限 1.0。永不加杠杆。目标：把黄金当低波动配置，通过"越贵越轻仓"降低回撤，换取更高夏普比率。适合追求低回撤、不追求高收益的投资者。
10Y_智能2.0_纯估值 ⭐10年滚动分位2.0分段函数 H(q)，q 为 10年滚动分位，上限 2.0。目标：平衡型。在低估区间适度加仓（最多 2 倍），高估区间大幅减仓，追求收益与回撤的最佳平衡。本看板推荐策略。
10Y_智能2.5_纯估值10年滚动分位2.5分段函数 H(q)，q 为 10年滚动分位，上限 2.5。目标：在智能2.0和智能3.0之间提供中间档。
10Y_智能3.0_纯估值10年滚动分位3.0分段函数 H(q)，q 为 10年滚动分位，上限 3.0。目标：进取型。在低估区间使用最高杠杆（3 倍），追求收益最大化。需承担更高的融资成本与回撤。
双乘积_智能3.0近1年 × 全部历史3.0q = 近1年分位 × 全部历史分位，代入 H(q)，上限 3.0。目标：探索多时间尺度信号融合。
⚠️ 风险提示：乘积不是标准分位，会系统性压低分位导致仓位偏高；在"近1年低估 + 全部历史高估"这类信号矛盾情形下会误判为低估并加杠杆。仅作方法论对照，不推荐实盘。
双取小_智能3.0min(近1年, 全部历史)3.0q = min(近1年分位, 全部历史分位)，代入 H(q)，上限 3.0。目标：用"保守取小"替代双乘积，信号矛盾时偏保守。
⚠️ 风险提示：仍非标准分位，且收益提升有限（vs 10Y_智能3.0），夏普反而下降。仅作方法论对照，不推荐实盘。

🧠 模型解读

回归方程： Ln(Gold) = 7.3935 + -0.3009×TIPS + -31.6054×CN_US_Spread + 0.0110×Gold_Oil_Ratio，R²=0.912

因子说明：

  • TIPS（美国10年期实际利率）：衡量持有黄金的机会成本。TIPS上升 → 黄金承压，系数为负，符合经典定价理论。
  • 中美利差（CN_US_Spread）：中国10年期国债收益率减美国10年期，捕捉全球资本在中美之间的分配逻辑。利差收窄/倒挂时，资本可能转向黄金等替代资产，推高金价。
  • 金油比（Gold_Oil_Ratio）：黄金与WTI原油的价格比率，反映避险情绪和大宗商品相对估值。比值上升往往意味着市场避险需求增强。
