## ④ 因子层级的发现

因子层级定律源于一个跨市场异常：**中美利差**在黄金、原油、债券、外汇、资本流动中是**双重身份因子**——既有高直接解释力，又有显著的交互效应。但在**全球15个权益市场**的检验中（Tang 2026e），它变为**纯规则因子**：直接 R² ≈ 0，交互 R² 却是直接的 1.78 倍。同一个变量在不同市场扮演不同角色。这种跨市场差异揭示了因子的功能并非天然"重要"或"不重要"——它取决于市场所处的体制。
