## 研究计划

我以独立研究者身份开展关于因子角色、结构—体制转换、统计表示、信息几何与科学可检验性的理论和方法论研究。以下名称用于组织和说明我的研究计划，表示由相关论文提出的框架，不代表已经获得机构采纳或成为学科共识。

### 核心概念

- **因子层级定律／因子层级体系：** 研究**体制因子**与**执行因子**之间的区分，并考察同一变量的解释作用或调节作用是否会随系统或体制改变。
- **切换度量论：** 为切换强度、切换类型、信息量与体制边界定位建立数学描述语言。
- **信息同构定律：** 研究统计表示在何种条件下保留与底层结构区分或体制边界有关的信息。
- **可检验性原则与可检验性规范：** 提出用于明确和审计因子重要性、结构变化及机制角色主张的操作性框架。该计划中的六个功能维度是搜索完整性、调节关系、结构断点、因果方向、问题完整性与流程闭环。
- **结构—体制理论：** 研究几何可识别性、机制约化、动力学临界性、统计可见性、模块结构以及结构性主张转换之间的接口。

**多体制状态解耦算法（MRSD）**属于较广研究计划中的实现工具层，而不是第五个核心概念组件。根据讨论问题不同，相关工作也会分别采用“因子层级体系”“信息同构认识论”和“科学发现操作系统”等表述。

## 阅读与评估研究成果

研究计划包含不同类型的工作：定义和形式化框架、在明确假设下证明的数学命题、方法论提案，以及经验或模型分析。这些类型不能相互替代。对于任一具体结论，应回到对应论文核查其定义、假设、证明步骤或数据设计、适用条件与局限。论文标题中使用“定律”“定理”或“统一理论”等术语，反映作者对该工作的表述方式，本身并不意味着相关主张已成为学科共识。

评估论文时，可以逐项核对：精确主张是什么？哪些假设不可缺少？结论属于定理、条件结果、经验发现还是猜想？它依赖哪些先前结果？所报告证据的适用范围是什么？是否存在独立复现或外部评价？这些区分在跨学科比较中尤其重要。

## 目录所涉及的研究领域

公开目录中的研究主题涉及多个领域，例如：

- **金融与资产定价：** 中美利差体制、黄金与原油定价、国债估值、汇率和资本流动。入门论文之一是 [2026a《双锚：中美因子共同决定全球黄金与原油定价》](https://doi.org/10.5281/zenodo.21091486)。
- **天文学：** 体制依赖测量、恒星模型一致性，以及作者提出的 K/G 过渡区“汤氏断点”（Tang Break）。
- **统计物理：** 涉及二维与三维 Ising 模型的信息论分析和结构断点分析；可参阅 [2026k](https://doi.org/10.5281/zenodo.21154577)。
- **粒子物理：** 基于粒子数据模式的体制边界分析。
- **化学：** 基于体制的周期趋势分析与钙—镧奇异性研究。
- **核物理：** 核壳结构、幻数与核素图的体制切换分析。
- **数学基础与研究方法论：** 切换度量、因子角色、保信息的统计表示、可检验性和结构性主张转型。

以上是对作者论文中研究方向与待检验主张的概述。各篇论文的证据类型、假设和适用范围不同；目前尚未在上述所有领域建立独立第三方复现。对具体结论应结合其来源论文的方法和局限逐项评估。
